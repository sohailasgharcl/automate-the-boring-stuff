# Automate the Boring Stuff with Python

Practice scripts and short programs from *Automate the Boring Stuff with Python* (Al Sweigart), organized one folder per chapter. Part of my backend developer learning path (Python first, then SQL, APIs and DevOps).

## Contents

| Folder | Topic | Files |
|---|---|---|
| chapter-1 | Python basics | python_basics.py |
| chapter-2 | Flow control | control_flow.py, guess_number.py, rpc_game.py |
| chapter-3 | Functions | functions.py, zigzag.py |
| chapter-4 | Lists | lists.py |
| chapter-5 | Dictionaries and structuring data | dictionaries.py |
| chapter-6 | Manipulating strings | manipulating_strings.py, pig_latin.py |

## Short programs

- Guess the Number (chapter-2)
- Rock, Paper, Scissors (chapter-2)
- Zigzag (chapter-3)
- Pig Latin (chapter-6)

## How to run

Requires Python 3. From the repo folder:

`python chapter-2/guess_number.py`
